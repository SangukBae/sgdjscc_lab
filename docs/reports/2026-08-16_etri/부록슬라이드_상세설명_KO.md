## 부록 A. 평가 입력 데이터 및 선택 기준

이 슬라이드는 이번 평가에 어떤 입력 데이터를 사용했는지, 그리고 왜 그 데이터를 골랐는지를 설명하는 슬라이드다. 핵심은 평가가 임의 예시 몇 개로 이루어진 것이 아니라, 정지 이미지와 영상의 의미 신뢰도를 각각 확인할 수 있도록 구성되었다는 점이다.

### 이미지 평가 입력

정지 이미지 평가는 Kodak 이미지 데이터셋을 기준으로 수행했다. Kodak은 이미지 복원, 압축, 전송 품질 평가에서 자주 쓰이는 표준적인 이미지 세트이므로, 복원 파이프라인이 안정적으로 동작하는지 확인하기에 적합하다.

평가는 다음 SNR 조건에서 수행했다.

```text
-5, 0, 5, 10, 15, 20, 25 dB
```

이 SNR sweep이 중요한 이유는 본 연구가 무선 채널을 통과한 뒤의 시맨틱 미디어 복원을 다루기 때문이다. 한 가지 SNR에서만 평가하면 채널이 나빠졌을 때와 좋아졌을 때 성능이 어떻게 변하는지 알 수 없다. 따라서 낮은 SNR부터 높은 SNR까지 변화시키면서 화질 지표와 의미 지표가 함께 어떻게 변하는지 확인한다.

이미지 평가는 전통적인 화질 지표와 시맨틱 지표를 함께 기록한다. 즉, 복원 이미지가 원본과 픽셀 단위로 가까운지만 보는 것이 아니라, 원래 전달하려던 객체와 의미 정보가 유지되는지도 함께 본다.

이미지 평가의 대표 산출물은 다음 파일이다.

```text
outputs/remote_hq_4090_20260816/image/kodak_snr_sweep.csv
```

### Kodak을 선택한 이유

Kodak은 같은 입력 이미지에 대해 여러 SNR 조건을 반복 평가하기 좋은 표준 이미지 세트다. 따라서 정지 이미지 복원의 품질과 의미 보존 정도를 재현 가능하게 비교할 수 있다.

다만 Kodak만으로는 영상의 시간축 문제를 평가할 수 없다. 예를 들어 객체가 프레임마다 깜빡이는지, 키프레임에서 멀어질수록 의미가 바뀌는지, 장면 전환을 제대로 처리하는지는 정지 이미지 평가만으로는 알 수 없다. 그래서 별도의 영상 평가 세트를 추가했다.

### 영상 평가 입력

영상 평가는 10개의 100-frame 시퀀스를 사용했다. 목적은 시맨틱 미디어 전송에서 중요한 여러 시간축 상황을 포함하는 것이다.

10개 영상은 다음과 같다.

```text
01 person walk
02 car pass
03 dog walk
04 person + car
05 camera pan person
06 handheld sign
07 person enter
08 car exit
09 scene cut chair car
10 busy sidewalk
```

각 영상은 서로 다른 의미 변화 또는 시간축 상황을 확인하기 위해 선택했다.

`person walk`는 단일 사람 객체가 시간축에서 계속 유지되는지 확인한다. `car pass`와 `dog walk`는 이동 객체를 다룬다. `person + car`는 여러 객체가 동시에 있을 때 두 객체가 함께 보존되는지 확인한다. `camera pan person`은 객체 의미는 크게 변하지 않지만 카메라 움직임이 큰 경우다. 이 경우 단순히 의미 변화만 보고 프레임을 재사용하면 화면 움직임을 놓칠 수 있으므로 중요하다. `handheld sign`은 흔들림과 구조 정보, 텍스트성 정보를 포함한다. `person enter`와 `car exit`는 객체가 새로 등장하거나 사라지는 상황을 확인한다. `scene cut chair car`는 장면 전환을 다룬다. `busy sidewalk`는 복잡한 배경과 여러 객체 후보가 있는 상황을 확인한다.

### Held-out 재측정

실모델 baseline 복원 후, 복원 영상은 OWLv2, VQA, ensemble 계열의 5개 모드로 다시 측정했다.

```text
10영상 x 5모드 = 50개 재측정 작업
```

이 절차가 중요한 이유는 최종 평가를 복원 루프 내부에서 사용한 지표와 분리하기 위해서다. 발표자료에서는 이를 held-out 재측정이라고 표현한다.

즉, 다음 두 가지를 구분한다.

1. 파이프라인이 실제로 영상을 복원하고 산출물을 만든다.
2. 복원 결과를 별도의 검증 경로로 다시 측정할 수 있다.

이렇게 해야 복원 과정에서 사용한 지표를 그대로 최종 성능 주장에 다시 사용하는 순환 평가 문제를 줄일 수 있다.

### 보고 범위

이 슬라이드는 현재 보고 범위도 함께 명시한다. 현재 자료는 평가 경로, 출력 파일, 재측정 절차가 확보되었다는 것을 보여 준다. 하지만 아직 모든 경쟁 모델과 동일한 실제 bitstream 또는 CBR 조건에서 우수성을 입증했다는 뜻은 아니다.

동일 CBR, fading 채널, 타 모델 공정 비교는 후속 작업으로 분리되어 있다.

## 부록 B-1 설명 전: 이 과제를 위해 새로 만든 지표

부록 B-1의 세부 계산식을 설명하기 전에, 이번 과제에서 새로 만든 지표가 무엇인지 먼저 짚고 넘어가는 것이 좋다. 기존의 PSNR, SSIM, LPIPS, CLIP은 이미 널리 쓰이는 기존 지표다. 이 과제에서 새로 정의하거나 확장한 핵심 지표는 **시맨틱 전송 신뢰도**를 보기 위한 SRS 계열과, 영상 시간축 의미 안정성을 보기 위한 PTC/SFR/SDI다.

가장 먼저 만든 것은 **SRS(Semantic Reliability Score)**다. SRS는 단순 화질이 아니라, 원본 또는 전송 의도가 복원 결과에 의미적으로 얼마나 남아 있는지를 하나의 점수로 보려는 지표다. CLIP 기반 전역 의미 유사도와 객체 보존율을 더하고, 객체 누락과 추가 객체를 penalty로 반영한다. 즉, “보기 좋은 이미지인가”보다 “보낸 의미가 유지되었는가”에 더 초점을 둔 점수다.

그 다음으로 영상 확장을 위해 새로 추가한 지표가 **PTC, SFR, SDI**다. 이 세 지표는 정지 이미지에서는 보이지 않는 시간축 문제를 보기 위한 것이다.

- **PTC(Packet-Temporal Consistency)**는 전송 packet과 복원 packet의 일치도가 영상 전체에서 얼마나 유지되는지를 본다.
- **SFR(Semantic Flicker Rate)**은 원본 변화로 설명되지 않는 객체의 비정상적인 등장과 사라짐, 즉 의미적 깜빡임을 본다.
- **SDI(Semantic Drift Index)**는 keyframe에서 멀어질수록 의미 불일치가 커지는지를 본다.

정리하면, 기존 지표는 PSNR, SSIM, LPIPS, CLIP이고, 이번 과제에서 강조해야 할 신규 지표는 **SRS**, 그리고 영상용으로 확장한 **PTC/SFR/SDI**다. 부록 B-1에서는 먼저 이미지와 단일 프레임 기준의 기존 지표와 SRS 계산 방식을 설명하고, 부록 B-2에서는 packet verifier와 PTC/SFR/SDI 계산 방식을 설명한다.

## 부록 B-1. 이미지·단일 프레임 평가지표 계산 방식

이 슬라이드는 정지 이미지와 영상의 개별 프레임에 적용되는 평가지표를 설명한다. 지표는 크게 세 그룹으로 나눌 수 있다.

1. 픽셀 단위 화질 지표
2. 지각 품질 및 전역 의미 유사도 지표
3. 객체 단위 의미 신뢰도 지표

세 그룹을 함께 쓰는 이유는 생성형 복원에서는 보기에 자연스러운 이미지가 반드시 원본 의미를 정확히 보존한다고 볼 수 없기 때문이다. 따라서 PSNR, SSIM 같은 전통 지표만으로는 부족하고, 객체와 의미 보존을 함께 봐야 한다.

### PSNR: 픽셀 왜곡

PSNR은 원본 이미지와 복원 이미지의 픽셀 단위 왜곡을 측정한다. 먼저 두 이미지의 평균 제곱 오차인 MSE를 계산하고, 이를 로그 스케일로 변환한다.

개념적으로는 다음과 같다.

```text
MSE = 평균 픽셀 제곱 오차
PSNR = 10 log10(MAX^2 / MSE)
```

MSE가 작을수록 PSNR은 커진다. 따라서 PSNR이 높다는 것은 복원 이미지의 픽셀이 원본에 더 가깝다는 뜻이다.

다만 PSNR은 의미 보존을 직접 측정하지 않는다. 생성 모델이 픽셀은 조금 다르게 만들었지만 의미는 잘 보존할 수도 있고, 반대로 PSNR이 어느 정도 높아도 중요한 객체가 사라졌을 수도 있다.

### SSIM: 구조 유사도

SSIM은 원본과 복원 이미지의 구조적 유사도를 측정한다. 밝기, 대비, 구조 항을 결합해 계산한다.

해석은 다음과 같다.

```text
SSIM이 높을수록 구조 보존이 좋다.
```

SSIM은 PSNR보다 사람이 느끼는 구조적 품질과 더 관련이 있지만, 여전히 프레임 단위 화질 지표다. 객체, 관계, 장면 의미가 제대로 보존되었는지를 직접 확인하지는 않는다.

### LPIPS: 지각 거리

LPIPS는 원본과 복원 이미지를 딥러닝 feature 공간에서 비교한다. 픽셀을 직접 비교하는 대신, 신경망의 여러 feature layer에서 추출한 표현의 거리를 계산한다.

개념적으로는 다음과 같다.

```text
LPIPS = 딥 feature 간 가중 거리
```

LPIPS는 낮을수록 좋다. 낮은 LPIPS는 사람이 보기에 원본과 복원 이미지의 차이가 작을 가능성이 높다는 뜻이다.

하지만 LPIPS도 구조화된 의미 검증 지표는 아니다. 따라서 객체가 누락되었는지, 없던 객체가 추가되었는지는 별도의 시맨틱 지표로 확인해야 한다.

### CLIP image-image 유사도

CLIP image-image 유사도는 원본 이미지의 CLIP image embedding과 복원 이미지의 CLIP image embedding 사이의 cosine similarity를 계산한다.

개념적으로는 다음과 같다.

```text
CLIP I-I = 원본 이미지 embedding과 복원 이미지 embedding의 cosine similarity
```

값이 높을수록 두 이미지가 CLIP의 전역 의미 공간에서 비슷하다는 뜻이다. 이는 픽셀 단위 일치보다 넓은 의미 유사도를 볼 수 있다는 장점이 있다.

### CLIP text-image 유사도

CLIP text-image 유사도는 caption의 text embedding과 복원 이미지의 image embedding을 비교한다.

개념적으로는 다음과 같다.

```text
CLIP T-I = caption embedding과 복원 이미지 embedding의 cosine similarity
```

이는 복원 이미지가 전송 또는 추출된 텍스트 설명과 얼마나 잘 맞는지를 측정한다. 수신단의 생성 복원 과정에서 caption 조건을 사용하기 때문에, 텍스트와 이미지의 의미 일치도는 중요한 참고 지표가 된다.

### 객체 보존·누락·추가 지표

의미 신뢰도를 더 직접적으로 평가하기 위해 원본 또는 전송 packet의 객체 집합과 복원 packet의 객체 집합을 비교한다.

정의는 다음과 같다.

```text
O_ref = 원본 또는 전송 packet의 객체 집합
O_rec = 복원 packet의 객체 집합
```

여기서 세 가지 비율을 계산한다.

```text
OPR = object preservation rate
MR  = missing object rate
AR  = additional object rate
```

OPR은 원본에 있던 객체가 복원 결과에 얼마나 남아 있는지를 나타낸다. MR은 원본에 있던 객체 중 복원에서 사라진 객체 비율이다. AR은 원본에는 없었지만 복원 결과에 새로 생긴 객체 비율이다.

이 지표는 hallucination 분석에 중요하다. 복원 이미지가 자연스러워 보여도, 원본에 없던 객체를 만들어냈다면 시맨틱 전송 관점에서는 신뢰도가 낮다.

### SRS: Semantic Reliability Score

SRS는 전역 의미 유사도와 객체 단위 의미 보존을 하나의 점수로 합친 지표다.

```text
SRS = 0.30*Cii + 0.25*Cti + 0.25*OPR - 0.10*MR - 0.10*AR
```

각 항의 의미는 다음과 같다.

```text
Cii = CLIP image-image similarity
Cti = CLIP text-image similarity
OPR = object preservation rate
MR  = missing object rate
AR  = additional object rate
```

복원 이미지가 원본과 의미적으로 비슷하고, caption과도 잘 맞으며, 원본 객체를 잘 보존하면 SRS가 높아진다. 반대로 객체가 누락되거나 추가 객체가 생기면 SRS가 낮아진다.

중요한 점은 SRS가 PSNR, SSIM, LPIPS를 대체하는 지표가 아니라는 것이다. 기존 화질 지표에 더해, 시맨틱 미디어 전송의 목표에 맞는 의미 신뢰도 축을 추가하는 역할을 한다.

## 부록 B-2. Packet Verifier·영상 시간축 지표 계산 방식

이 슬라이드는 packet 검증과 영상 시간축 평가 지표를 설명한다.

핵심 배경은 정지 이미지 지표만으로는 영상 복원의 문제를 설명하기 어렵다는 점이다. 프레임 하나하나는 괜찮아 보여도, 영상 전체에서는 객체가 깜빡이거나, 키프레임에서 멀어질수록 의미가 달라지거나, 원본에는 없는 객체가 시간축에서 반복적으로 나타날 수 있다.

### Packet Verifier severity

Packet Verifier는 전송 semantic packet과 복원 이미지 또는 복원 프레임에서 다시 추출한 semantic packet을 비교한다.

오류는 다음 다섯 가지로 나누어 본다.

```text
객체 누락
추가 객체
관계 오류
속성 오류
장면 불일치
```

이 오류들을 하나의 severity 점수로 합친다.

```text
severity = 0.30*e_miss
         + 0.25*e_add
         + 0.20*e_rel
         + 0.15*e_attr
         + 0.10*e_scene
```

해석은 다음과 같다.

```text
severity가 0에 가까움 = packet 일치도가 좋음
severity가 커짐 = 의미 불일치가 커짐
```

객체 누락과 추가 객체에 높은 가중치를 둔 이유는 이 두 오류가 송신 의도와 hallucination 문제에 직접적으로 연결되기 때문이다.

### Packet consistency

Packet consistency는 한 프레임에서 전송 packet과 복원 packet이 얼마나 일치하는지를 나타내는 frame-level 점수다.

슬라이드에서는 다음 형태로 정의한다.

```text
C_pkt(t) = 0.50*C_obj(t)
         + 0.20*C_rel(t)
         + 0.20*C_attr(t)
         + 0.10*C_scene(t)
```

각 항의 의미는 다음과 같다.

```text
C_obj(t)   = frame t의 객체 일치도
C_rel(t)   = frame t의 관계 일치도
C_attr(t)  = frame t의 속성 일치도
C_scene(t) = frame t의 장면 일치도
```

이 값은 PTC와 SDI를 계산할 때 기본 frame-level consistency로 사용된다.

### PTC: Packet-Temporal Consistency

PTC는 전송된 의미가 영상 전체에서 계속 유지되는지를 측정한다.

슬라이드의 간단한 계산식은 다음과 같다.

```text
PTC = mean_t C_pkt(t)
```

즉, 각 프레임의 packet consistency를 계산한 뒤 시간축으로 평균낸다.

해석은 다음과 같다.

```text
PTC가 높음 = 보낸 의미가 영상 전체에서 더 안정적으로 유지됨
```

PTC는 한 프레임만 보는 것이 아니라 전체 영상에서 의미 일치가 얼마나 유지되는지를 요약한다는 점에서 중요하다.

### SFR: Semantic Flicker Rate

SFR은 비정상적인 객체 깜빡임을 측정한다. 여기서 깜빡임은 복원 영상에서 객체가 생기거나 사라졌지만, 원본 또는 reference packet 변화로는 설명되지 않는 경우를 말한다.

슬라이드의 간단한 계산식은 다음과 같다.

```text
SFR = mean_t spurious_birth_death(t) / union_objects(t)
```

여기서 중요한 단어는 `spurious`다. 원본 영상에서 실제로 사람이 들어오거나 차가 나가는 경우는 정상적인 변화이므로 오류로 세지 않는다. SFR은 원본 변화로 설명되지 않는 객체 등장과 사라짐만 계산한다.

해석은 다음과 같다.

```text
SFR이 낮음 = 설명되지 않는 객체 깜빡임이 적음
```

이 지표는 생성 기반 영상 복원에서 특히 중요하다. 생성 모델은 중간 프레임을 그럴듯하게 만들 수 있지만, 객체의 존재가 프레임마다 불안정해질 수 있기 때문이다.

### SDI: Semantic Drift Index

SDI는 키프레임에서 멀어질수록 의미 불일치가 커지는지를 측정한다.

슬라이드의 간단한 계산식은 다음과 같다.

```text
SDI = slope_LS(1 - C_pkt(t) vs keyframe_distance(t))
```

여기서:

```text
1 - C_pkt(t) = frame t의 packet drift
keyframe_distance(t) = 최근 keyframe으로부터의 거리
slope_LS = 최소제곱 회귀 기울기
```

SDI가 양수이고 클수록, 키프레임에서 멀어질수록 의미 오류가 증가하는 경향이 있다는 뜻이다. SDI가 0에 가까우면 keyframe 거리 증가에 따른 drift 경향이 크지 않다는 뜻이다.

해석은 다음과 같다.

```text
SDI가 0에 가까움 = 시간축 의미가 안정적
SDI가 큰 양수 = keyframe에서 멀어질수록 의미 drift 증가
```

### Temporal SRS

Temporal SRS는 영상 전체의 의미 신뢰도를 요약하기 위한 지표다.

슬라이드의 간단한 계산식은 다음과 같다.

```text
Temporal SRS = mean_t SRS(t) + packet score summary
```

즉, 프레임별 SRS와 packet 기반 신뢰도 점수를 시간축으로 집계해 영상 단위 의미 신뢰도를 만든다.

Temporal SRS는 전체 요약값으로 유용하지만, 단독으로만 보면 짧은 구간의 심각한 오류가 평균에 묻힐 수 있다. 그래서 PTC, SFR, SDI와 함께 해석해야 한다.

### Held-out 해석 원칙

슬라이드 하단의 문장은 최종 성능 주장은 loop-internal 지표와 분리된 held-out 재측정을 기준으로 해야 한다는 뜻이다.

복원 루프 안에서 어떤 지표를 사용해 재생성 여부나 guidance 조정을 결정했다면, 같은 지표를 그대로 최종 성능 주장에 쓰는 것은 순환 평가가 될 수 있다. 따라서 최종 평가는 OWLv2/VQA 재측정, GT object-only, open-world 모드처럼 별도 경로에서 측정한 값을 기준으로 해석한다.

### 핵심 요약

이 슬라이드에서 가장 중요한 신규 시간축 지표는 다음 세 가지다.

```text
PTC: 보낸 의미가 시간축에서 유지되는가
SFR: 원본 변화로 설명되지 않는 객체 깜빡임이 있는가
SDI: keyframe에서 멀어질수록 의미 drift가 증가하는가
```

이 세 지표를 통해 정지 이미지 중심의 의미 신뢰도 평가를 영상 시간축 의미 신뢰도 평가로 확장한다.
